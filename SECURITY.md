# Security Policy

## Supported versions

The project is under active development. Please use the latest version from the `main` branch.

## Reporting a vulnerability

If you discover a security issue, please report it privately and responsibly.

Do not open a public issue for security vulnerabilities.

Please contact the maintainer directly through the repository owner or the preferred private channel for this project.

## Response expectations

We will review reports as quickly as possible and work to patch verified issues in a timely manner.

## Responsible disclosure

We appreciate reports that are clear, actionable, and include enough information to reproduce and validate the issue.

Please avoid exposing sensitive details in public discussions until the issue has been addressed.
