# Contributing to OX-ELL

Thanks for your interest in contributing to OX-ELL.

## How to contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes with clear, focused commits.
4. Run the relevant checks or tests.
5. Open a pull request with a concise explanation of the change.

## Code style

-    Keep changes focused and easy to review.
-    Prefer clear naming and readable code.
-    Add comments only where necessary.
-    Update documentation when behavior changes.

## Reporting issues

Please open an issue describing:

-    the problem
-    steps to reproduce it
-    expected behavior
-    any relevant logs or screenshots

## Pull request checklist

-    The change is scoped and tested
-    The description clearly explains the purpose
-    Documentation is updated if required
-    The branch is rebased or up to date with `main`

## Community

Be respectful and constructive in discussions. We welcome thoughtful feedback and improvements.
